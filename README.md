# Dahu releases

Windows installers and the automatic-update feed for **Dahu**, a direct-modelling CAD application.

- Download the latest installer from [Releases](https://github.com/mscanga/dahu-releases/releases/latest).
- Installed copies check this repository for updates (`latest.json`); update packages are signed and verified
  by the app before they are installed.
- Dahu is free software under the GNU Affero General Public License v3.0. The complete corresponding source code of
  each version is attached to its release as `dahu-<version>-source.zip`.

This repository holds release files only; development happens elsewhere.
